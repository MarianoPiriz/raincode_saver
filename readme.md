# Vanilla JS + Vite Boilerplate

Un entorno de desarrollo minimalista, ultra rápido y optimizado para prototipar o construir aplicaciones web modernas utilizando **JavaScript vanilla** y **Vite**.

---

## 🚀 Características

- ⚡ **Vite**: Servidor de desarrollo ultrarrápido con Hot Module Replacement (HMR).
- 🛠️ **Vanilla JS**: Sin frameworks ni sobrecarga de dependencias.
- 🎨 **Soporte para CSS/SCSS**: Importación directa de hojas de estilo en tus módulos.
- 📁 **Estructura limpia**: Organización de archivos simple e intuitiva.
- 📦 **Pronto para producción**: Compilación y minificación automatizada con Rollup.

---

## 📋 Requisitos Previos

Asegúrate de tener instalado en tu sistema:

- [Node.js](https://nodejs.org/) (versión 18.0 o superior recomendada)
- [npm](https://www.npmjs.com/) (incluido con Node.js) o `pnpm` / `yarn`
